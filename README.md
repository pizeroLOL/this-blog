# this blog

又一个个人博客，这次准备整点 astro ssg + tailwindcss。

博客文章具体位置在 [这里](./src/blogs/)

## 开发

图片资源（png / jpg / webp / svg 等）通过 [Git LFS](https://git-lfs.com/) 存储，
克隆仓库前先安装并初始化：

```bash
git lfs install
git clone https://github.com/pizeroLOL/this-blog.git
```

```bash
pnpm install
pnpm dev
```
